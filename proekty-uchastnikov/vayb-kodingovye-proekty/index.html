    Вайб-кодинг проекты

    Участники сообщества самостоятельно пишут программы с помощью LLM для автоматизации юридических задач. Ниже -- проекты, которые авторы открыто представили в чате. Если вашего проекта нет в списке, или в карточке есть ошибка, сообщите об этом через форму обратной связи.
