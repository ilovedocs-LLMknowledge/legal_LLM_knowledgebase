## Что в этом разделе

-  [OpenClaw](./openclaw) — open-source фреймворк для технически подготовленных специалистов; кейсы: проверка персональных данных, товарные знаки, закон о языке

-  [Claude Cowork](./claude-cowork) — десктопный агент от Anthropic для работы с локальными документами; кейсы: судебные решения, медицинская документация, договоры займа

-  [Perplexity Computer](./perplexity-computer) — облачный мультимодельный агент; кейсы: сайт для адвоката, анализ корпоративных рисков, юридические документы. Результат требует самостоятельной проверки

**Агентные IDE** (Cursor, Windsurf, Claude Code, GitHub Copilot, Kiro, Google Antigravity, OpenAI Codex) — отдельный класс инструментов для написания кода. Для юридической практики прямого применения немного, кроме [вайб-кодинга](./../../../instrumenty/vayb-koding/_index). Сравнительный обзор всех семи — в дополнительных материалах ниже.
