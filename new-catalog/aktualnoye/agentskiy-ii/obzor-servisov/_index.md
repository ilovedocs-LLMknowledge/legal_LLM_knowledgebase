## Что в этом разделе

-  [OpenClaw](./openclaw) -- open-source фреймворк для технически подготовленных специалистов; кейсы: проверка персональных данных, товарные знаки, закон о языке

-  [Claude Cowork](./claude-cowork) -- десктопный агент от Anthropic для работы с локальными документами; кейсы: судебные решения, медицинская документация, договоры займа

-  [Codex](./codex) -- десктопный агент от OpenAI; решает те же задачи, что и Cowork, при более щедрых лимитах и интерфейсе на русском; кейсы: возражения по судебному делу, перенос скиллов из Cowork, интерфейс к API Росреестра

-  [Perplexity Computer](./perplexity-computer) -- облачный мультимодельный агент; кейсы: сайт для адвоката, анализ корпоративных рисков, юридические документы. Результат требует самостоятельной проверки

**Агентные IDE** (Cursor, Windsurf, Claude Code, GitHub Copilot, Kiro, Google Antigravity) -- отдельный класс инструментов для написания кода. Для юридической практики прямого применения немного, кроме [вайб-кодинга](./../../../instrumenty/vayb-koding/_index). OpenAI Codex изначально из этой же семьи, но в десктопной версии используется юристами и как универсальный документный агент -- поэтому вынесен в отдельную статью. Сравнительный обзор всех семи кодовых IDE -- в дополнительных материалах ниже.
