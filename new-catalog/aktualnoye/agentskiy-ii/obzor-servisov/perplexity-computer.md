## Описание

**Тип:** облачный мультимодельный агент\
**Запуск:** 25 февраля 2026

Perplexity Computer работает полностью в облаке и оркестрирует около двух десятков AI-моделей одновременно. Пользователь сам выбирает **модель-оркестратор** -- ту, что планирует работу, распределяет подзадачи и сводит результат; выбрать можно из нескольких фронтирных моделей, а также сменить оркестратор и по ходу выполнения задачи. К оркестратору добавляются специализированные модели: отдельные для глубоких исследований, для подзадач, для изображений и видео. Конкретный набор моделей сервис меняет несколько раз в год, актуальный список -- в [журнале обновлений Perplexity](https://www.perplexity.ai/changelog).

Принципиальное отличие от [агентов-ассистентов](./agenty-assistenty) и [Claude Cowork](./claude-cowork): нет доступа к локальным файлам. У Cowork сессия тоже по умолчанию идет в облаке, но он дотягивается до папок на вашем компьютере через десктоп-приложение -- Perplexity Computer такой возможности не дает вовсе. Исключение -- подключение собственных MCP-серверов. Это снижает гибкость в работе с локальными данными, но устраняет риски, связанные с глубоким доступом к устройству.

## Кейсы из практики сообщества

*Своими кейсами поделились выпускники курса Рунетлекс Академии* [*«Нейросети для юриста»*](https://runetlex-academy.ru/neuralnetworks) *Дмитрий Миллер и Елена Ива, а также ментор курса Евдокия Шматина.*

| **Юридические документы**    | Претензия по рекламе БАД -- на корпоративном бланке с аргументацией, в формате .docx                                                         | Хорошая претензия; потребовалась полная вычитка -- дважды исправлены неточности в ссылках на закон | 166 / 6 мин       |
|                              | Отзыв на иск (12 л.) и претензия (9 л.)                                                                                                      | Применена устаревшая ставка ЦБ, ссылка на неактуальное постановление; требует проверки             | --                |
| **Аналитика и исследования** | Поиск судебной практики по точной фразе в Гаранте (логин и пароль предоставлены пользователем)                                               | Нашел всю практику из КонсультантПлюса и дополнительно несколько материалов                        | \~1000 / \~30 мин |
|                              | Анализ возможных нарушений прежнего директора, пошаговый план устранения рисков -- 20-страничный отчет .docx                                 | Устаревшие данные (ставка ЦБ); требует проверки                                                    | --                |
| **Создание контента**        | Слайды из видео (23 шт.) + транскрипция с временными метками                                                                                 | Слайды -- только начало видео, не все; транскрипция -- слово в слово, метки -- секунда в секунду   | \~2000            |
|                              | Сайт для адвоката на WordPress                                                                                                               | «Хоть прямо сейчас заливать на хостинг»                                                            | --                |
| **Автоматизация**            | Скилл `reklama-pretenziya-bad` с правовой базой, алгоритмом и разобранным примером -- для повторного использования на аналогичных претензиях | --                                                                                                 | в рамках задачи   |

Во всех задачах, связанных с нормами права, результат потребовал самостоятельной проверки: ошибки модели могут быть неочевидны без дополнительного контроля.
