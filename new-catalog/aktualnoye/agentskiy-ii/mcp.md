<note type="info">

MCP (Model Context Protocol) — открытый стандарт от Anthropic для подключения AI-агентов к внешним системам. Благодаря MCP агент может работать с данными из CRM, почты, корпоративных баз данных — через единый протокол вместо отдельной интеграции под каждый сервис.

</note>

**Дата составления:** 2026-03-30\
**Статус:** ✅ Актуально

---

## Суть

Агент умеет работать с инструментами — но инструменты нужно как-то подключить. Раньше каждый разработчик делал это по-своему: писал собственный код для интеграции с Gmail, потом еще отдельный код для Slack, потом для CRM. Каждое подключение — уникальная работа.

MCP решает эту проблему. Это стандарт, который описывает общий язык между AI-агентом и внешними сервисами. Разработчик создает MCP-сервер для своего инструмента один раз — и этот сервер начинает работать с любым агентом, который поддерживает MCP.

Anthropic опубликовала спецификацию MCP в конце 2024 года и сделала ее открытой. Сейчас протокол поддерживают Claude (Cowork и API), Cursor, Windsurf, VS Code Copilot и другие инструменты.

---

## Как это работает

MCP-сервер — это программа, которая:

-  Подключается к конкретному сервису (Gmail, Jira, Notion);

-  «Объявляет» агенту, какие функции доступны: прочитать письмо, найти документ, создать задачу;

-  Исполняет запросы от агента и возвращает результаты.

Агент не знает, как устроен Gmail внутри. Он просто видит, что через MCP-сервер ему доступны функции «прочитать письмо», «найти письма по теме», «отправить ответ» — и вызывает их по мере необходимости.

---

## Для чего это нужно в юридической работе

MCP превращает разрозненные корпоративные системы в единое рабочее пространство агента. Вместо того чтобы переключаться между интерфейсами и копировать данные вручную, агент сам забирает нужное из каждой системы.

Практически это означает, что агент может: получить задачу из системы управления проектами, открыть нужные документы из корпоративного хранилища, проверить историю переписки по делу, сформировать итоговый документ — все в рамках одной сессии.

Примеры уже существующих MCP-серверов: Google Drive, Gmail, Slack, Asana, Jira, GitHub, DocuSign, FactSet (финансовые данные). В конце февраля 2026 Anthropic подключила эти сервисы к Claude Cowork в рамках движения в сторону enterprise.

---

## Разница между MCP и плагином

MCP — это протокол (стандарт подключения). Плагин — это готовый пакет. Плагин может включать в себя один или несколько MCP-коннекторов, плюс скиллы с инструкциями, плюс команды для удобного вызова. MCP-сервер — это один из компонентов внутри плагина, но не то же самое, что плагин.
