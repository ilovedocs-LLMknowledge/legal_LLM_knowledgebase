<note type="info">

Кастомизация агента -- это набор способов донастроить его под свою работу: подключить к внешним системам, научить выполнять задачи по конкретной методике, упаковать готовые решения. Эти способы постепенно стандартизируются на уровне отрасли и применимы для всех популярных мультиагентных систем.

</note>

**Дата составления:** 2026-05-03\
**Статус:** 💡 Актуально

## Три уровня кастомизации

У современных агентных систем три главных способа расширения их функционала, эффективно дополняющие друг друга:

**MCP-серверы** -- подключение агента к внешним системам. Через MCP агент получает доступ к Gmail, корпоративному хранилищу, CRM, базам нормативных актов. MCP -- это открытый протокол под управлением Linux Foundation; один и тот же сервер работает с любым MCP-совместимым агентом.

**Скиллы** -- инструкции для агента в формате `SKILL.md`. Пишутся на обычном языке: что проверять, в каком порядке, как оформлять результат. Загружаются только при необходимости -- в контексте постоянно хранится только краткое описание. Сейчас скиллы -- это формирующийся отраслевой стандарт.

**Плагины** -- пакеты, объединяющие скиллы, MCP-коннекторы и команды в единое решение под конкретную задачу. Юридический плагин Anthropic, например, включает скиллы по анализу NDA и проверке персональных данных, MCP-коннекторы к корпоративным системам, slash-команды для удобного вызова.

В дополнение к этим трем универсальным механизмам, у каждой платформы есть свои надстройки -- отдельные интерфейсы установки, маркетплейсы, специфические форматы. Для Claude они собраны в статье [Кастомизация Claude](./kastomizaciya-claude).

## Что где работает

|                                  | **Claude** (Anthropic)                              | **Codex** (OpenAI)                 | **OpenClaw**                               |
|----------------------------------|-----------------------------------------------------|------------------------------------|--------------------------------------------|
| **MCP-серверы**                  | Да: чат, Cowork, Code, аддоны Excel/PowerPoint, API | Да: CLI, IDE-расширение, Codex App | Да, в основе платформы                     |
| **Скиллы** (`SKILL.md`)          | Да, во всех интерфейсах                             | Да                                 | Да, более 3 200 скиллов в ClawHub          |
| **Плагины**                      | Да, в Code и Cowork (23+ официальных)               | Да, через Codex marketplace        | Да, через ClawHub                          |
| **Маркетплейсы**                 | Anthropic Marketplace, сторонние GitHub-каталоги    | Codex marketplace, GitHub          | ClawHub                                    |
| **Создание скилла через диалог** | `Skill Creator` (мета-скилл)                        | `$skill-creator`                   | через инструменты ClawHub                  |
| **Сборка плагина через диалог**  | `create-cowork-plugin` (в Cowork)                   | `$plugin-creator`                  | TypeScript-модули, преимущественно вручную |
