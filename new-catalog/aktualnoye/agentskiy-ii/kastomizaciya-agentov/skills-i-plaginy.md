Скиллы -- это инструкции для агента в формате Markdown: что проверять, в каком порядке, какой результат выдавать. Плагины собирают скиллы вместе с командами и интеграциями в готовый пакет под конкретную задачу. Концепция универсальная -- одинаково работает в Claude, Codex (OpenAI) и OpenClaw.

</note>

## Скиллы

Скилл (Skill) -- файл `SKILL.md` с двумя частями: метаданными в YAML-заголовке и инструкциями в тексте. Агент читает этот файл перед выполнением задачи, как читают должностную инструкцию перед работой.

```
---
name: contract-review
description: Анализ договора на юридические риски
allowed-tools: "Read, Write"
version: 1.0.0
---

# Инструкция по анализу договора

Ты юрист, специализирующийся на российском праве.
Твоя задача -- провести анализ переданного договора.

## Шаг 1: Стороны и предмет
...
```

Принципиальное отличие от системного промпта: инструкции скилла не находятся в контексте постоянно -- загружаются только при активации. В контексте хранится лишь краткое описание. Это позволяет иметь много скиллов, не перегружая агента, и вызывать их по мере необходимости.

Формат `SKILL.md` стал отраслевым стандартом. Anthropic предложил его первым в Claude Code, OpenAI явно перенял в Codex (под названием **Open Agent Skills Standard**), OpenClaw использует тот же формат. Один и тот же скилл, написанный для Claude, обычно работает и в Codex, и в OpenClaw (могут потребоваться некоторые доработки).

## Плагины

Плагин -- это пакет, который объединяет четыре компонента в одно решение под конкретную задачу:

**Скиллы** -- инструкции под конкретные задачи (анализ NDA, проверка персональных данных, подготовка стенограммы).

**Команды** -- slash-команды для удобного вызова скиллов: `/legal:review-nda`, `/legal:check-pd`.

**Коннекторы** -- MCP-интеграции с внешними сервисами: корпоративное хранилище документов, CRM, почта.

**Субагенты** -- параллельные исполнители для сложных задач, когда несколько подзадач можно выполнять одновременно.

Манифест и способы установки у каждой платформы свои -- у Claude это `.claude-plugin/plugin.json`, у Codex `.codex-plugin/plugin.json`, у OpenClaw -- TypeScript-модули. Но логика одинаковая: один пакет, который ставится одной командой и сразу дает агенту все нужное для конкретной работы.

## Создание скилла

Самый простой способ -- встроенный мета-скилл, который сам создает скиллы по описанию. Он задает уточняющие вопросы, изучает образцы вашей работы, предлагает структуру инструкции. В Claude это `Skill Creator`, в Codex -- `$skill-creator`, в OpenClaw -- инструменты ClawHub.

Что можно встроить в скилл: образцы документов с нужным форматированием, словари терминов, логотипы для колонтитулов, ссылки на типовые проверки.

<note type="tip">

Пример скилла: обработка стенограмм аудиозаписей -- проверка терминологии по глоссарию, исправление ошибок распознавания речи, форматирование по образцу Word-файла с корпоративным логотипом.

</note>

**Рекомендации:** не перегружайте скилл -- если инструкция становится слишком длинной, качество падает. Делитесь скиллами с коллегами (без конфиденциальной информации).
