## Подключение MCP-серверов

В Claude два механизма подключения MCP, и работают они по-разному.

**Remote MCP** (по HTTP/SSE) -- подключаются напрямую, во всех интерфейсах одинаково: Customize -> Connectors -> «+», вставить URL сервера, при необходимости пройти OAuth. Это работает в Claude.ai (чат), Cowork, Claude Desktop, мобильном приложении.

**Local MCP** (stdio через `claude_desktop_config.json`) -- запускаются на компьютере пользователя. Их подключают Claude Desktop и Claude Code напрямую через конфигурационный файл. **В Cowork локальные MCP-серверы напрямую не подключаются** -- их нужно оборачивать в плагин. И даже с оберткой локальный сервер работает лишь пока на этом компьютере открыто десктоп-приложение Claude: облачная сессия дотягивается до локальных инструментов только через него.

## Где живут скиллы

Скиллы в Claude хранятся в нескольких местах:

| Местоположение                         | Что это                                                                                                          |
|----------------------------------------|------------------------------------------------------------------------------------------------------------------|
| `~/.claude/skills/`                    | Личные скиллы пользователя -- доступны во всех проектах. Используются Claude Code и Claude Desktop.              |
| `.claude/skills/` (внутри репозитория) | Скиллы конкретного проекта -- коммитятся в git, доступны всей команде                                            |
| Customize -> Skills (в чате и Cowork)  | Скиллы, установленные через интерфейс. Отображаются в едином списке: Anthropic, ваши, организационные, плагинные |
| Аддоны Excel и PowerPoint              | Скиллы, включенные в настройках Claude, автоматически доступны в аддонах                                         |

Один и тот же скилл может работать в нескольких интерфейсах -- Claude адаптирует его под среду: например, скилл по подготовке отчета в Cowork выдаст Word-документ, а в Excel-аддоне -- разбивку по листам.

## Маркетплейс плагинов

Anthropic ведет официальный [маркетплейс плагинов](https://claude.ai/marketplace). На старте в январе 2026 в нем было 11 плагинов, к 24 февраля каталог расширился еще на 12 -- для HR, инженерии, дизайна, операционной работы и финансовых услуг. К маю 2026 в каталоге более 23 официальных open-source плагинов.

Помимо официального, есть сторонние маркетплейсы на GitHub -- их подключают как дополнительные источники. Так распространяются командные и корпоративные наборы плагинов, а также наработки сообщества.

## Способы установки плагина в Cowork

В Cowork есть четыре способа установить плагин:

**Из официального маркетплейса Anthropic.** Cowork -> Marketplace -> найти плагин -> Install -> Authorize. Так ставятся официальные плагины и плагины из подключенных каталогов.

**Из стороннего маркетплейса на GitHub.** Кнопка «+» в плагинах -> «Add marketplace from GitHub» -> URL репозитория. Так распространяются командные и корпоративные наборы.

**Через сборку плагина внутри Cowork.** Встроенный скилл `create-cowork-plugin` собирает плагин по описанию, которое вы даете в чате, и выдает кнопку «Install» прямо в диалоге. Удобно для оборачивания собственного MCP-сервера -- именно так Алексей Мынка подключал NotebookLM.

**Через локальную загрузку файла.** Plugins -> Upload plugin. В мае 2026 у этого пути есть [известный баг](https://github.com/anthropics/claude-code/issues/40414): backend принимает только `.zip`, а файлы с расширением `.plugin` отклоняются с ошибкой «Only .zip files are accepted». Обходной путь -- переименовать `.plugin` в `.zip` и загрузить.

## Skill Creator: как создать скилл диалогом

`Skill Creator` -- встроенный мета-скилл Claude, который помогает создавать другие скиллы в диалоговом режиме. Запускается командой в чате; агент задает уточняющие вопросы, изучает ваши наработки и предлагает структуру инструкции. На выходе -- готовый `SKILL.md`, который можно сразу установить или сохранить в файл.

Что можно встроить в скилл: образцы документов с нужным форматированием, словари терминов, логотипы для колонтитулов, ссылки на типовые проверки.

## Teach Claude: запись скилла действиями

В Cowork есть отдельная функция **Teach Claude**: вы показываете агенту последовательность действий голосом и мышью -- например, как экспортировать документ в Word через конкретное меню -- и агент запоминает это как скилл, который потом можно вызывать по команде.

Удобно для процедур, которые сложно описать словами, но легко показать -- работа с конкретным интерфейсом, нестандартные форматы экспорта, специфические настройки шаблонов.
