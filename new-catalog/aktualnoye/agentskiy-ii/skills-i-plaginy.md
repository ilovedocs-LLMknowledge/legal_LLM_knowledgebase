</note>

## Что такое скилл

Скилл (Skill) -- файл `SKILL.md` с двумя частями: метаданными в YAML-заголовке и инструкциями в тексте. Агент читает этот файл перед выполнением задачи, как читают должностную инструкцию перед работой.

```
---
name: contract-review
description: Анализ договора на юридические риски
allowed-tools: "Read, Write"
version: 1.0.0
---

# Инструкция по анализу договора

Ты юрист, специализирующийся на российском праве.
Твоя задача — провести анализ переданного договора.

## Шаг 1: Стороны и предмет
...
```

Принципиальное отличие от системного промпта: инструкции скилла не находятся в контексте постоянно -- загружаются только при активации. В контексте хранится лишь краткое описание. Это позволяет иметь много скиллов, не перегружая агента.

Скиллы находятся в нескольких местах: пользовательские (`~/.config/claude/skills/`), проектные (`.claude/skills/`), плагинные и встроенные. Агент видит все доступные скиллы и может активировать нужный.

## Что такое плагин

Плагин -- это готовый пакет, который включает четыре компонента:

**Скиллы** -- инструкции под конкретные задачи (например, анализ NDA, проверка персональных данных, подготовка стенограммы).

**Команды** -- slash-команды для удобного вызова скиллов, например `/legal:review-nda` или `/legal:check-pd`.

**Коннекторы** -- MCP-интеграции с внешними сервисами: корпоративное хранилище документов, CRM, почта.

**Субагенты** -- параллельные исполнители для сложных задач, когда несколько подзадач можно выполнять одновременно.

Anthropic ведет официальный [маркетплейс плагинов](https://claude.ai/marketplace); одиннадцать open-source плагинов уже выпущены, включая [юридический (`legal`)](https://github.com/anthropics/knowledge-work-plugins/tree/main/legal). Можно создать и командный маркетплейс для внутреннего использования.

## Как создать скилл

Наиболее простой способ -- встроенный инструмент **Skill Creator**. Это мета-скилл, который помогает создавать другие скиллы в диалоговом режиме: агент задает уточняющие вопросы, изучает ваши наработки и предлагает структуру инструкции.

Что можно встроить в скилл: образцы документов с нужным форматированием, словари терминов, логотипы для колонтитулов, ссылки на типовые проверки.

<note type="quote">

Пример скилла: обработка стенограмм аудиозаписей  -- проверка терминологии по глоссарию, исправление ошибок распознавания речи, форматирование по образцу Word-файла с корпоративным логотипом.

</note>

**Рекомендации:** не перегружайте скилл -- если инструкция становится слишком длинной, качество падает. Делитесь скиллами с коллегами (без конфиденциальной информации).

## Teach Claude

В Claude Cowork есть функция **Teach Claude**: вы показываете агенту последовательность действий голосом и мышью -- например, как экспортировать документ в Word через конкретное меню -- и агент запоминает это как скилл, который затем можно вызывать по команде.
