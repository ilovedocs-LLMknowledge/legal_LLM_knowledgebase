## Инструкции для Claude

Общие правила для всех задач -- стиль ответов, оформление, порядок работы -- задаются в настройках, в разделе Instructions for Claude. Правила по конкретному делу или клиенту удобнее держать в инструкциях проекта, а для Claude Code -- в файле `CLAUDE.md` в папке проекта.

Инструкции читаются в каждой задаче, поэтому держите их короткими. Длинную методику -- как проверять договор или оформлять заключение -- лучше вынести в скилл: он загружается, только когда нужен. Почему это важно, разобрано в статье [Контекстная инженерия](./../upravlenie-agentami/kontekstnaya-inzheneriya).

## Скиллы

Скиллы находятся в разделе Customize -> Skills. Там четыре группы:

-  Встроенные скиллы Anthropic для Word, Excel, PowerPoint и PDF -- Claude применяет их сам, когда нужно;

-  Ваши собственные скиллы;

-  Скиллы, которыми с вами поделились коллеги, -- они выключены, пока вы их не включите;

-  Скиллы организации -- в корпоративных тарифах.

Для работы скиллов должно быть включено выполнение кода (в настройках, раздел Capabilities).

**Как добавить скилл:**

-  **Попросить Claude.** Скилл можно создать прямо в разговоре: опишите процедуру или покажите образцы, и Claude сохранит их как скилл. Встроенный скилл skill-creator задает уточняющие вопросы, изучает ваши наработки и предлагает структуру инструкции, а на выходе дает готовый `SKILL.md`.

-  **Показать действиями.** В десктоп-приложении есть функция Record a Skill (в меню «+»): вы выполняете задачу на экране и комментируете голосом, а Claude превращает запись в скилл. Удобно для процедур, которые сложно описать словами, но легко показать: работа с конкретным интерфейсом, нестандартный экспорт, настройки шаблонов.

-  **Загрузить архив.** Customize -> Skills -> «+» -> Create skill -> Upload a skill: папка скилла упаковывается в `.zip`.

**Где работают скиллы.** Включенные скиллы доступны в приложении на любом устройстве, в Claude Code (при входе тем же аккаунтом), в надстройках для Word, Excel, PowerPoint и Outlook (в боковой панели скилл вызывается через `/`) и в надстройке для Google Docs, Sheets и Slides. Claude подстраивает скилл под окно: скилл подготовки отчета в приложении выдаст документ Word, а в надстройке Excel -- разбивку по листам.

## Плагины

Плагин -- пакет, который одним действием добавляет скиллы, MCP-коннекторы, субагентов и хуки (скрипты, которые срабатывают в определенные моменты работы). Плагины ставятся в разделе Customize -> Plugins.

**Способы установки:**

-  **Из официального каталога.** Browse plugins -> выбрать плагин -> Install. Если в плагин входит коннектор, Claude попросит войти в соответствующий сервис.

-  **Из Git-репозитория.** Add marketplace -> адрес репозитория на GitHub (полный или в виде `владелец/репозиторий`); подходят и открытые репозитории на GitLab и Bitbucket. Плагины из репозитория появляются рядом с остальными. Так распространяются командные, корпоративные и общественные наборы плагинов.

-  **Из файла.** На странице Plugins есть загрузка пакета плагина.

-  **Собрать в разговоре.** Плагин можно попросить собрать по описанию -- например, чтобы обернуть в него собственный MCP-сервер и передать коллегам.

**Обновления.** Claude проверяет обновления плагинов в том каталоге, откуда они установлены, и предупреждает, если вы меняли файлы плагина у себя и обновление их перезапишет.

**Где работают плагины.** В агентных задачах Claude и в Claude Code. Плагины с локальными MCP-серверами работают, только пока открыто десктоп-приложение.

Сторонние скиллы и плагины -- это инструкции и код, которые агент выполняет от вашего имени, поэтому ставьте их из проверенных источников. Плагины, которые сделали участники сообщества, собраны в подборке [Плагины и MCP сообщества](./plaginy-ot-soobshchestva).

## Коннекторы и MCP-серверы

**Удаленные серверы** работают в интернете и подключаются по адресу: Customize -> Connectors -> добавить свой коннектор -> вставить адрес сервера и при необходимости пройти авторизацию. Коннектор привязывается к аккаунту и работает на всех устройствах, в том числе в облачных задачах. Так, например, подключается [MCP-коннектор к Базе](./../../razvitie-bazy-znanii/mcp-konnektor).

**Локальные серверы** запускаются на вашем компьютере. Их добавляют в настройках десктоп-приложения (раздел для разработчиков, файл `claude_desktop_config.json`) или ставят одним файлом как расширение десктоп-приложения. Облачная задача дотягивается до них только через Claude Desktop, поэтому работают они, пока приложение открыто. Чтобы поставить такой сервер на другом компьютере или передать коллегам, его удобно упаковать в плагин.

**В Claude Code** MCP-серверы подключаются командой `claude mcp add` или файлом `.mcp.json` в папке проекта.

Что такое MCP и чем он отличается от плагина -- в статье [MCP-серверы](./mcp).

### Пример: связка с Gemini Notebook (NotebookLM)

[Gemini Notebook](./../../instrumenty/specializirovannye-ii-servisy/notebooklm) можно подключить к Claude как инструмент: агент сам обращается к вашим ноутбукам, добавляет источники и задает вопросы. Это позволяет разделить работу: тяжелую аналитику по большому массиву документов (30+ файлов, веб-исследования, кросс-референсы) бесплатно берет на себя Gemini Notebook, а Claude тратит лимиты только на оркестрацию и финальный результат.

Подключение -- одноразовая настройка из трех шагов: установить библиотеку `notebooklm-py` и авторизоваться в Google, поднять локальный MCP-сервер и подключить его к Claude через плагин-обертку. Сервер локальный, поэтому работает, пока на компьютере открыт Claude Desktop. Готовый плагин и серверный вариант коннектора лежат в подборке [Плагины и MCP сообщества](./plaginy-ot-soobshchestva).

Подробные инструкции по подключению:

-  Под macOS -- пост [Тимура Умарова](https://t.me/docsllm/68008);

-  Под Windows -- инструкция выпускника курса [«Нейросети для юриста: от основ к системе»](https://runetlex-academy.ru/neuralnetworks) Алексея Мынки:
