## Облик харнесса крупнейших лабораторий

За 2026 год агентные продукты Anthropic и OpenAI сошлись к очень похожему облику. У каждой лаборатории один агентный движок и несколько окон к нему: приложение для любых задач с агентом внутри, отдельная среда для кода, работа с папками, браузером и экраном через десктоп-приложение, задачи по расписанию, агент в рабочем мессенджере и постоянно включенный проактивный агент. Поэтому почти любой сценарий из статьи [Агентные сценарии работы](./../agentnye-scenarii) можно повторить и в Claude, и в ChatGPT. Различаются детали: где идет работа, что агент видит и как часто он спрашивает подтверждение.

Остальные харнессы движутся к тому же облику: одни начинали с браузерного агента, другие -- с терминала или среды разработки, но набор возможностей у всех сближается.

## Содержание раздела

-  [Агентные возможности Claude](./agentnye-vozmozhnosti-claude) -- приложение на вебе, десктопе и телефоне, Claude Code, браузер и надстройки: папки на диске, обработка данных, советы по работе

-  [Агентные возможности ChatGPT и Codex](./agentnye-vozmozhnosti-chatgpt) -- режимы Chat и Work, Codex, браузер и надстройки: папки на диске, облачная и локальная работа, советы по работе

-  [Агенты-ассистенты](./agenty-assistenty) -- агенты, которые работают постоянно и живут в мессенджере (Hermes, OpenClaw): как устроены, что решить до запуска, безопасность; кейсы юристов сообщества

## Другие агентные харнессы

Агентных продуктов сейчас так много, что со счета сбиться нетрудно. Ниже -- основные на октябрь 2026 года. Почти все они движутся к тому же облику: агент для любых задач, среда для кода, работа с файлами и браузером, задачи по расписанию, скиллы и MCP. Продукты, рассчитанные только на программистов, отмечены отдельно.

**Google**

-  [**Gemini Spark**](https://gemini.google.com) -- постоянно работающий агент в приложении Gemini: выполняет фоновые задачи в Gmail, Документах и на Диске и работает в браузере.

-  [**Gemini Enterprise**](https://cloud.google.com/gemini-enterprise) -- рабочий агент Google для компаний, который ведет многошаговые задачи по документам, почте и файлам; готовится отдельная редакция для юристов.

-  [**Gemini Notebook (NotebookLM)**](./../../instrumenty/specializirovannye-ii-servisy/notebooklm) -- исследовательское пространство по вашим источникам с агентным режимом: выполняет код, применяет скиллы и выгружает результат в Word, Excel и PowerPoint.

-  [**Antigravity**](https://antigravity.google) и [**Jules**](https://jules.google) -- десктопная среда и терминальная программа с агентами (в нее влился Gemini CLI) и облачный агент;  для программистов.

**Другие компании США и Европы**

-  [**Copilot Cowork**](https://www.microsoft.com/en-us/microsoft-365/blog/2026/06/16/copilot-cowork-is-now-generally-available/) -- агент Microsoft 365 Copilot для многошаговых задач в Word, Excel, PowerPoint, Outlook и Teams, сделанный вместе с Anthropic.

-  [**GitHub Copilot**](https://github.com/features/copilot) -- десктопное приложение, терминальная программа, облачный агент и режим агента в средах разработки; только для программистов.

-  [**Perplexity Computer, Personal Computer и Comet**](./../../instrumenty/specializirovannye-ii-servisy/perplexity) -- облачный мультимодельный агент, его версия с доступом к компьютеру и браузер с ассистентом.

-  **Muse** (Meta) -- постоянно работающий личный агент в облачной виртуальной машине с браузером и файлами; пока только в США.

-  [**Manus**](https://manus.im) -- облачный агент общего назначения: исследования, документы, презентации и сайты.

-  **Grok Bot и Grok Build** (xAI) -- постоянно работающие «ИИ-коллеги» со своим облачным компьютером и терминальный агент для кода.

-  [**Amazon Quick**](https://aws.amazon.com/quick) -- рабочий агент AWS на компьютере, в вебе и на телефоне: локальные файлы, почта, календарь, отчеты со ссылками на источники. Для программистов у Amazon есть [Kiro](https://kiro.dev).

-  [**Mistral Vibe**](https://mistral.ai/news/vibe-agent/) (бывший Le Chat) -- европейский ассистент с рабочим режимом Vibe Work и агентом для кода Vibe Code.

-  [**Cursor**](https://cursor.com) и [**Devin Desktop**](https://devin.ai) (бывший Windsurf) -- среды разработки с агентами; только для программистов.

**Китайские лаборатории**

-  [**Kimi**](https://www.kimi.com) (Moonshot AI) -- агентный режим Kimi Agent и десктопное приложение Kimi Work: документы, слайды, исследования, работа с папками и браузером. Для кода -- Kimi Code.

-  **QwenWork и приложение Qwen** (Alibaba) -- рабочий агент с десктопным клиентом и офисный ассистент с задачами по расписанию. Для кода -- [Qwen Code](https://github.com/QwenLM/qwen-code).

-  [**Z.ai**](https://z.ai) (модели GLM) -- агентный режим в чате, который готовит документы, таблицы и слайды, и десктопный харнесс ZCode; вебинар о ZCode -- в материалах к статье [Харнесс](./../upravlenie-agentami/harness).

-  [**MiniMax Code**](https://agent.minimax.io) (MiniMax) -- десктопный агент с рабочим режимом и режимом для кода.

-  [**Doubao Work**](https://www.doubao.com) (ByteDance) -- офисный агент на компьютере: документы, слайды, таблицы и локальные файлы. Для кода -- среда разработки [TRAE](https://www.trae.ai).

-  **WorkBuddy** (Tencent) -- десктопный агент для работы с документами Word, Excel, PowerPoint и PDF в выбранных папках, совместимый со скиллами OpenClaw.

-  **DuMate** (Baidu) -- десктопный и мобильный агент, который сам работает с программами и файлами.

**Открытые и независимые проекты**

-  [**OpenClaw и Hermes Agent**](./agenty-assistenty) -- агенты-ассистенты, которые вы разворачиваете сами и с которыми общаетесь через мессенджеры.

-  [**LM Studio Bionic**](https://lmstudio.ai) -- агент для открытых моделей, которые работают на вашем компьютере или в облаке LM Studio: документы, папки, таблицы. О локальных моделях -- в разделе [Локальные LLM](./../../instrumenty/lokalnye-llm/_index).

-  **OpenCode, Crush, Cline, Kilo Code** -- открытые агенты в терминале и средах разработки; для программистов.
