## Суть

Большинство ведущих LLM-сервисов — ChatGPT, Claude, Gemini — работают в США и самостоятельно соблюдают американский санкционный режим: блокируют доступ с российских IP-адресов. Указанные сервисы не запрещены российскими регуляторами, это сами сервисы не принимают российских пользователей.

Соответственно, использование программно-аппаратных средств доступа к информационным ресурсам, информационно-телекоммуникационным сетям, работающим по технологии «виртуальная частная сеть», для доступа к LLM-сервисам из России — не является нарушением российского законодательства. Это означает, что пользователь в России, работающий с Claude или ChatGPT через VPN, нарушает условия использования сервиса (Terms of Service), но не российский закон.

---

## Как получить доступ к зарубежным LLM

Базовый сценарий — VPN, **не предоставляющий доступ к заблокированным российскими регуляторами ресурам**, с подключением через страну, не попавшую под ограничения.

Полноценный функционал большинства флагманских сервисов становится доступным при оплате подписки. Для оплаты подписки нужна карта, принимаемая сервисом. Работающие способы на момент написания:

-  **Виртуальные карты** зарубежных эмитентов — выпускаются без личной явки в отделения банков с помощью посредников (например, Citora).

-  **Покупка подписки через посредников** (например, через Авито, plati.market) — менее надежный способ, зависит от конкретного продавца. Доступ к приобретенной таким образом аккаунтам в любой момент может быть прерван. Ориентируйтесь на отзывы на платформе, и будьте готовы к тому, что предоставленный вам аккаунт может оказаться в любой момент заблокированным.

-  **Карта иностранного банка** — если есть счет за рубежом.

-  **Американский Apple ID + подарочные карты App Store** — для владельцев iPhone: создается аккаунт с допускаемым сервисом регионом, подписка оплачивается подарочными картами, которые можно купить онлайн.

Конкретные актуальные варианты можно отслеживать в обсуждениях сообщества: ситуация меняется, и то, что работало несколько месяцев назад, может уже не работать.

Кроме международных флагманов, есть бесплатные варианты без VPN:

-  **DeepSeek** — семейство моделей и сервис из Китая. Бесплатен, доступен из России, хорошо справляется с юридическими задачами на русском языке. Рекомендуется как стартовый вариант для тех, кто только начинает.

-  **Qwen** — еще одна китайская модель, доступная без VPN, поддерживает русский язык.

-  **GigaChat** (Сбербанк) и **YandexGPT** — российские модели, доступны без VPN, принимают российские карты. По ряду задач уступают международным флагманам.

Использовать их или нет — зависит от задачи и требований к конфиденциальности.
